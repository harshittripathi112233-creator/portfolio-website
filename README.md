# Personal Portfolio Website

A responsive personal portfolio website built for my third-year Computer Science web development project.

## Technologies Used
* **HTML5:** Semantic structure and layout
* **CSS3:** Custom styling, CSS Grid/Flexbox, and responsive design
* **JavaScript:** Interactive UI components

## How to Run
To view this project locally:
1. Download or clone this repository.
2. Ensure `index.html`, `study.css`,`script.js` and your image file are in the exact same folder.
3. Open `index.html` in any modern web browser.
